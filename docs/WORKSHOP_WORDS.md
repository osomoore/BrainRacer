# Adventure Workshop: hard words for beginning readers

Report only; nothing here is applied. Words a child aged 5-7 (sounding out) would likely struggle with in aspect labels,
variant names, scenario titles and buttons. Already shortened: Extra, Bumper, Test (see the word-simplifying package).
Each variant name also shows in the model list on the board and in the shop, so a rename touches both.
