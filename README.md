# BrainRacer

Top-down open-world co-op racer for 1–2 players (Xbox-style USB controllers or keyboard). Race through a procedurally generated city to shared goals while answering quick picture, word and math challenges. Correct answers fire a turbo boost. Watch out for police, trucks and, halfway through, a giant dinosaur.

## Play
- Double-click `play.bat` (builds, starts a local server, opens the browser full screen), or
- `npm install && npm run assets && npm run dev` → http://localhost:5173

## Controls
| | Gamepad | Keyboard P1 | Keyboard P2 |
|---|---|---|---|
| Steer | Left stick / D-pad | A / D | ← / → |
| Go | RT or A | W | ↑ |
| Brake / reverse | LT | S | ↓ |
| Answers (left / center / right) | X / Y / B | 1 / 2 / 3 | , / . / / |
| Pause | Start | Esc | Esc |

See `docs/PLAN.md` for the full design.
