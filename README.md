# BrainRacer

A browser lane-racer where every gate asks a math question. Steer into the lane with the right answer to score and speed up; a wrong answer costs a life.

## Run
Open `index.html` in a browser (no build step).

## Controls
- ← / → switch lanes
- Space start / restart

## Ideas
- Other question types (memory, patterns, words)
- Difficulty ramp, high scores, sound, touch controls
